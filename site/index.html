Is a culture drifting toward senescence as it is expanded? Check it, and refuse to answer when the data can't support it.

SenGuard-MSC tracks a published senescence signature across passages, donor by donor. Your data stays in this browser. It is a research prototype: it does not measure potency, immune function or clinical safety, and it makes no pass or fail call.

How it works

  1. Check. Gene identifiers, data scale, transformation, signature coverage, sequencing depth, sample identity and passage design. Each check exists because of a failure we met in public data.
  2. Normalize. Median-of-ratios for counts, verified against PyDESeq2 to 1e-14, using the published filters. FPKM is rescaled to TPM.
  3. Score. Published SenCat weights: log1p applied once, then a weighted sum with no intercept. The weights are fetched from the authors' repository at a pinned commit and their SHA-256 is verified on load.
  4. Trend, within each donor. Slope and rank correlation against passage. Donors are never pooled into one absolute scale, because absolute scores shift between labs and media.
  5. Control. Random gene sets of the same size and weights show whether a rise is specific to this signature.
  6. Second readout. A culture-drift clock, a ridge model we trained on within-donor gene ranks across MSC cohorts and tested by leaving out each cohort in turn. It estimates passage-like drift and is not a senescence measure.

This page runs the same analysis as the validated Python pipeline. Automated tests compare the two: scores agree within 1e-13. Code, protocols and result tables.

What it cannot tell you

  • Not potency. Nothing here measures T-cell suppression, immune function, therapeutic effect or safety.
  • Not a release test. No threshold has been validated, so a rising score doesn't mean a lot has failed and a flat one doesn't mean it is fine.
  • Not a substitute for assays. Public MSC cohorts rarely have per-sample senescence assays, so this reports trends and not accuracy.
  • Partly time in culture. Passage, culture time and possibly batch move together in these datasets.
